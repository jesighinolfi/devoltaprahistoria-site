Política de privacidade

Última atualização: outubro de 2026.

Sobre a aplicação

«De Volta pra História uploader» é uma ferramenta interna usada exclusivamente pela equipe do canal De Volta pra História para publicar e gerir vídeos do próprio canal no YouTube. Ela não é oferecida ao público.

Dados acessados

A aplicação usa a YouTube Data API apenas na conta do próprio canal, para enviar vídeos, definir títulos, descrições, miniaturas e playlists e consultar o estado dos envios. Nenhum dado de outros usuários é coletado.

Armazenamento e partilha

As credenciais de acesso ficam guardadas de forma privada nos equipamentos da equipe. Nenhum dado é vendido, partilhado com terceiros ou usado para publicidade.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados obtidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
